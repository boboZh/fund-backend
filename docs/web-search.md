# AI 联网搜索

`/ai/chat` 提供 `search_web` 工具，复用现有工具调用、进度提示和聊天记录流程。
研报无相关内容或信息不足时，模型应继续联网；近期走势和最新消息直接联网。
用户指定只看研报时不联网。网页以 Markdown 链接引用，研报继续使用原有编号引用。

搜索供应商为 Tavily，使用项目已有的 axios，无需安装新依赖。
在后端运行环境中配置 `TAVILY_API_KEY` 后重启服务。开发环境可配置到本机
`.env.dev`，不要将真实密钥提交到仓库。未配置时工具会明确返回配置缺失，
不会声称联网成功。本文不修改开发或生产环境配置。

接口说明：https://docs.tavily.com/documentation/api-reference/endpoint/search

搜索最多返回 5 条网页摘要，每条最多 2000 字符，15 秒超时，支持取消。
日期未知时不把结果当作最新消息，搜索摘要也不等同于实时交易行情。
只发送公开问题，工具说明要求模型不发送用户持仓和金额。

验证示例：询问“英伟达的股票接下来的走势”，应出现联网搜索步骤及网页来源链接；
询问未入库公司的研报观点，应在研报不足后联网补查；联网不可用时应说明具体限制。
